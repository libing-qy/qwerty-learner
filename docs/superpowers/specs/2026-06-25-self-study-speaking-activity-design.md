# 自考英语一 00012 第一章节命名设计

## 1. 背景

`self-study_English1_00012` 词库已经调整为单章词库，当前 37 个词全部归入第 1 章。

新的需求是：将该词库的第一章节命名为 `Speaking Activity`，但只影响“章节选择相关界面”，不改结果页、导出文件名、内部章节索引或其它词库的默认章节文案。

## 2. 目标与非目标

### 2.1 目标

- `self-study_English1_00012` 的第 1 章在章节选择相关界面显示为 `Speaking Activity`。
- 其它词库继续保持现有默认章节命名。
- 未配置自定义标题的章节继续回退到现有默认文案。
- 改动集中在词库元数据和章节标题读取层，避免在多个组件里分散写死词库判断。

### 2.2 非目标

- 不修改结果页中的章节标题文案。
- 不修改导出文件名中的章节文案。
- 不修改数据库、章节索引、章节统计或章节完成逻辑。
- 不为所有页面一次性引入全局文案替换，仅覆盖本次确认的章节选择相关界面。

## 3. 方案选择

### 方案 A：组件内硬编码判断

在每个章节选择组件中判断：若词库 id 为 `self-study_English1_00012` 且章节索引为 `0`，则显示 `Speaking Activity`。

优点：
- 实现最快。

缺点：
- 判断分散，后续维护成本高。
- 如果以后还有别的词库自定义章节名，需要重复复制逻辑。

### 方案 B：为词库增加章节标题元数据（推荐）

在词库元数据中增加可选章节标题配置，例如 `chapterTitles`。界面统一通过一个小工具函数读取：有配置则显示配置标题，否则回退默认标题。

优点：
- 数据与展示职责清晰。
- 便于未来扩展到其它词库或其它章节。
- 避免多个组件写死判断。

缺点：
- 比硬编码多一层轻量抽象。

### 方案 C：新增专用章节命名表

在资源目录外额外维护一个章节命名映射表。

优点：
- 配置集中。

缺点：
- 与现有词库资源脱节。
- 对本次单词库级小需求偏重。

**结论：采用方案 B。**

## 4. 设计

### 4.1 词库元数据扩展

在 `DictionaryResource` / `Dictionary` 上增加可选 `chapterTitles?: string[]`。

对于 `self-study_English1_00012`：

- `chapterCount = 1`
- `chapterTitles = ['Speaking Activity']`

### 4.2 标题读取规则

新增统一章节标题读取逻辑：

- 若当前词库存在 `chapterTitles[index]`，则使用该标题。
- 否则回退到组件现有默认文案：
  - 中文场景：`第 N 章`
  - 英文卡片场景：`Chapter N`

这保证现有绝大多数组件行为保持不变，仅该词库的目标章节显示自定义名称。

### 4.3 影响界面

只修改这三处章节选择相关界面：

1. `Typing` 页顶部章节切换
   - 文件：`src/pages/Typing/components/DictChapterButton/index.tsx`
   - 当前显示 `第 N 章`
   - 新行为：若有自定义标题则显示标题

2. `Gallery` 页章节卡片
   - 文件：`src/pages/Gallery/ChapterButton.tsx`
   - 当前显示 `Chapter N`
   - 新行为：若有自定义标题则显示标题

3. `Gallery-N` 词库详情弹层中的章节列表
   - 文件：`src/pages/Gallery-N/DictDetail/index.tsx`
   - 当前章节项默认按序号展示
   - 新行为：将章节标题透传给章节项，若有自定义标题则显示标题

## 5. 组件边界

### 5.1 统一工具函数

建议新增轻量工具函数，例如：

- 输入：词库对象、章节索引、默认前缀类型
- 输出：最终显示文案

这样可以减少每个组件里重复写回退逻辑。

### 5.2 `ChapterButton`

由仅接受 `index` 扩展为接受显式标题文本，例如 `title`。组件只负责展示，不负责推导词库逻辑。

### 5.3 `DictDetail` 内章节项

章节项组件若当前没有可接收自定义标题的能力，则增加一个可选标题入参；若已有展示层组件，则在其调用层处理标题并透传。

## 6. 测试策略

采用最小 TDD：

1. 先新增/修改测试，验证 `self-study_English1_00012` 暴露出 `chapterTitles: ['Speaking Activity']`。
2. 为至少一个章节选择 UI 增加展示断言，验证自定义标题会渲染。
3. 验证未配置标题的普通词库仍显示默认章节文案。

## 7. 风险与兼容性

- 风险较低：仅为词库元数据增加可选字段，不影响未使用该字段的旧逻辑。
- 兼容性良好：所有未配置 `chapterTitles` 的词库继续按原行为展示。
- 范围受控：结果页、导出命名、统计和数据库逻辑不在本次变更内。
